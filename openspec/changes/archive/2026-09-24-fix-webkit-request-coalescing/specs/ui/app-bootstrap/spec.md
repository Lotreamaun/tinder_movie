## ADDED Requirements

### Requirement: Предзагрузка очереди фильмов без дубликатов

Очередь фильмов, набранная приложением при старте, SHALL состоять из разных фильмов — по одному на каждый запрос «следующего фильма». Гарантия SHALL держаться независимо от движка WebView, в том числе там, где сетевой слой склеивает одинаковые одновременные запросы и раздаёт им общий ответ.

#### Scenario: Предзагрузка при открытии приложения
- **WHEN** приложение стартует и набирает начальную очередь фильмов
- **THEN** в очереди нет двух одинаковых фильмов, и первые нажатия лайк/дизлайк сменяют карточку каждое

#### Scenario: Открытие в Telegram на iOS/macOS
- **WHEN** приложение открыто в клиенте Telegram на WebKit (iPhone, macOS), где одинаковые одновременные запросы склеиваются сетевым слоем
- **THEN** каждый запрос очереди всё равно получает собственный фильм, а не копию одного ответа

#### Scenario: Догрузка при быстрых свайпах
- **WHEN** пользователь свайпает быстро и несколько запросов «следующего фильма» оказываются в полёте одновременно
- **THEN** каждый из них получает собственный фильм, и в очередь не попадают дубликаты
