Очередь схлопывается дедупом до одного фильма, поэтому нажатие идёт по ветке пустой очереди и следующий фильм совпадает с текущим по `id`. По кадрам анимации: лайк — старая карточка уезжает `x: 0 → 500`, `opacity: 1 → 0`, затем её DOM-узел удаляется и новый проявляется до `opacity: 1`; дизлайк — то же с `x: 0 → -414…-500`. В обоих случаях в DOM остаётся ровно одна карточка и это **новый** узел, то есть нажатие не пропадает
